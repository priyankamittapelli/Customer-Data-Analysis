# Customer Data Analysis

## Project Overview
This project analyzes customer shopping behavior using SQL, Excel, and Microsoft Power BI.

The dataset contains shopping information from 10 shopping malls in Istanbul between 2021 and 2023.

## Project Objectives
- Analyze shopping distribution by gender.
- Identify which gender purchases more products.
- Compare revenue generated by different genders.
- Analyze customer age groups and purchasing patterns.
- Study product category distribution.
- Analyze payment methods.
- Create an interactive Power BI dashboard.
- Provide business insights and recommendations.

## Tools Used
- SQL – Data querying and analysis
- Microsoft Excel – Analysis results
- Microsoft Power BI – Dashboard and visualization
